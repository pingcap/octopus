
# 新建测试任务

### 接口地址
> /test

### 请求方式
> POST

### 请求参数
> 
```js
{
	"user" : "请求者标识",
	"from" : "上游信息", // eg. slack / git PR / cron ...
	"note" : "备注信息"
	"callback" : "回调地址" // (可选) 任务结束状态回调通知
	"packages" : [
		{
			"repo" : "名称", // tidb / tikv / pd
			"branch" : "分支名称",
			"githash" : "Git 提交标识",
			"tag" : "",
			"binaryurl" : "二进制包获取地址", // (可选) 若缺失，则按照默认拼接规则生成包url地址
			"platform" : ""
		}
		// ....
	]
}
```

### 响应数据
> 
> | http code | 含义 |
> |:------|:---|
> | 200 | 成功 |
> | 400 | 失败 |
> 
```js
{
	"jobid" : "成功生成成的任务id", // 字符串id, 若任务创建失败, 此处为空串
}
```

# 获取任务运行历史

### 接口地址
> /history

### 请求方式
> GET

### 请求参数
> | url参数 | 可选 | 含义 |
> | ------ |:---|:----|
> | ndays | Y | 查看过去 n 天历史 ( 默认7天 ) |

### 响应数据
> 
> | http code | 含义 |
> |:------|:---|
> | 200 | 成功 |
> | 400 | 失败 |
> 
```js
// PS : 任务列表按创建时间降序返回
{
	"since" : "时间上区间",
	"till" 	: "时间下区间",
	"jobs" : [
		{
			"job_id" : "任务id",
			"creator" : "创建者标识",
			"status" : "任务状态"
			"create_time" : "任务创建时间",
			"from" : "任务触发源",
			"note" : "任务备注信息",
		},
		// ......
	]
}
```



# 获取单个任务详细信息

### 接口地址
> /job/${job_id}

### 请求方式
> GET

### 请求参数
> | url参数 | 可选 | 含义 |
> | ------ |:----|:---|
> | job_id | N | 目标任务id |

### 响应数据
> | http code | 含义 |
> |:------|:---|
> | 200 | 成功 |
> | 404 | 任务不存在 |
>
```js
{
	"job_id" : "任务id",
	"creator" : "创建者标识",
	"status" : "任务状态"
	"create_time" : "任务创建时间",
	"from" : "任务触发源",
	"note" : "任务备注信息",
}
```



# 终止任务

### 接口地址
> /job/${job_id}

### 请求方式
> DELETE

### 请求参数
> | url参数 | 可选 | 含义 |
> | ------ |:----|:---|
> | job_id | N | 目标任务id |
>
```js
{
	"user" : "请求者标识", // (可选)
	"note" : "备注信息", // (可选)
}
```

### 响应数据
> | http code | 含义 |
> |:------|:---|
> | 200 | 成功 |
> | 404 | 任务不存在 |
>
```js
{
	"msg" : "消息"
}
```



# 任务状态对应表 
> | 状态码   		| 含义            	      |
> | :----------- |:-----------------------|
> | pending   	| 任务已创建, 待执行        |
> | deploying   	| 任务运行中, 正在部署集群   |
> | testing   	| 任务运行中, 正在执行测试   |
> | finish   		| 任务已完成 			      |
> | aborted   	| 任务被中止 (人为/异常)     |
